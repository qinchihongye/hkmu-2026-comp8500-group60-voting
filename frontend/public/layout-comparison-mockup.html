二、底部操作按钮 [ Cancel ] 与 [ Save draft ] 的排布效果
现状效果 (Current)

现状：两个按钮挤在右下角 (gap 12px)

问题点：取消与保存紧挨在一起，容易误触取消导致辛苦填写的表单重置。

推荐方案 (Space-Between 两端对齐)

推荐：Cancel 靠最左侧，Save draft 靠最右侧 (防误触)

优点：两端拉开安全距离，防止误触；与我们刚刚优化好的 SharePanel 底部动作条（左侧复制、右侧预览）保持统一的视觉节奏与交互心智。

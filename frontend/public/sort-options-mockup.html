Public Polls 排序选项设计方案

针对用户需求：“按开始时间，按截止时间，按人气”在 Public polls 筛选栏中的三种视觉与交互形态

方案 A · 强烈推荐

高保真胶囊式下拉选择器 (Capsule Dropdown)

★ 兼顾空间与扩展性

在红框区域嵌入优雅的微光胶囊按钮，默认显示当前排序规则。点击展开平滑毛玻璃浮层，直接点选排序方式。不挤占左右两侧控件，移动端与窄屏适配极佳。

🔥最高人气 (最多票数) ✓
⏳即将截止 (截止时间) ✓
🚀最新开始 (开始时间) ✓
🆕最新发布 (默认排序) ✓
🎯 空间占用最克制 单一行内胶囊宽度约 160px，即使在 1024px 分辨率下也不会发生换行折叠。
✨ 状态指示明确 胶囊上常驻当前激活的排序标签（如“最高人气”），用户一眼即知当前视图顺序。
🛠️ 易于扩展多语言 中英文名称切换自由（"Most popular", "Closing soon", "Start time"）。

方案 B：分段双轨标签组 (Segmented Pill Tabs)

平铺直选 · 零下拉操作

将四种排序方式做成与右侧状态 Tabs 风格完全一致的分段药丸组，平铺在搜索框右侧。

⚡ 单击直达 无需展开下拉，直接点击任意标签即刻排序。
⚠️ 横向宽度敏感 平铺标签约需 280px-320px 宽度，在窄屏或笔记本上容易挤压搜索框宽度。
🎨 视觉同质化 与右侧的 Status Tabs 并列出现两个 Segmented Control，视觉上有一定重复感。

方案 C：胶囊下拉 + 升降序切换钮 (Direction Toggle Capsule)

精细化排序控制

在下拉胶囊旁附带一个独立的升降序切换图标按钮（`↓ 降序` / `↑ 升序`），满足部分用户希望按“最早截止”或“最晚截止”自由倒序的深度需求。

🔄 双向调节 支持正序（从远到近/从少到多）与倒序。
🤔 认知成本略高 对普通投票广场用户而言，一般只看“即将截止”或“最热”，切换正逆序频率相对较低。
📐 布局规整 比方案 B 更节省水平宽度，圆钮与胶囊搭配优雅。

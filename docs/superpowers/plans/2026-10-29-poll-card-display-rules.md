# 投票卡片展示规则

* **目标**：32 种投票设置组合共用一套卡片组件，根据状态、票数上限和访问权限展示对应内容。

  日期：2026-10-29。本文件记录已讨论的展示规则，是后续实现依据，不代表代码已经实现。适用于普通投票，不增加“示例”分类、特殊标识或置顶规则。界面支持中英文，代码和标识符使用英文。

## 卡片布局

* **按固定顺序组织内容，状态与访问规则分开显示。**

  | 顺序 | 内容 | 规则 |
  |---|---|---|
  | 1 | 标题＋状态 | 状态显示未开始、进行中、已结束；管理页面可显示草稿 |
  | 2 | 投票规则 | 记名／匿名 · 公开／私密 · 单选／多选 |
  | 3 | 时间 | 未开始显示开始时间；进行中显示剩余时间；结束显示结束原因 |
  | 4 | 进度 | 有上限显示选票进度，无上限显示时间进度 |
  | 5 | 描述 | 最多两行，没有则省略 |
  | 6 | 操作 | 一个主要按钮，必要时增加查看结果的次级入口 |

  标题最多显示两行，完整标题在详情页可见。卡片由内容撑开，不压缩或裁掉规则、进度、按钮；同一行卡片的操作区尽量底部对齐。窄屏改为单列，标签允许换行。

  不显示参与者头像、示例编号、字体标注或开发说明。私密放在规则行，不能替代进行中／已结束状态。颜色之外始终提供文字，不能只用颜色表达状态或进度类型。

## 进度条规则

* **票数上限决定进度类型；一张卡片只显示一种主进度。**

  | 条件 | 示例 | 计算方式 | 颜色 |
  |---|---|---|---|
  | vote_limit 有值 | 已收选票：12 / 20 · 60% | ballot_count / vote_limit × 100% | 蓝色 |
  | vote_limit 为 null | 时间进度：40% | (当前时间－开始时间) / (结束时间－开始时间) × 100% | 紫色 |

  进度名称必须明确，不能都只写 Progress。英文建议使用 Ballots received 和 Time elapsed。

  计数单位是选票份数，不是人数或选项数。多选一次提交仍算一份；以后若支持每日一次，同一账户跨日提交也累计计入全场额度。没有总参与人数数据时，不称为“参与率”。

  进度限制在 0%–100%。进度条使用实际比例，文字可显示整数百分比；未达到上限或截止时间时使用向下取整，避免提前显示 100%。数据缺失显示“—”，不当作 0，不补造票数。非法上限或结束不晚于开始时不计算进度，展示不可用状态并记录异常。

  有上限的投票仍保留上方时间行，因此能同时了解容量与截止时间。不要再叠加第二条时间进度造成混淆。

## 生命周期与操作

* **先判断状态，再决定进度与按钮。**

  草稿先按管理状态处理；非草稿优先检查显式关闭，再检查是否到期、是否尚未开始，否则为进行中。实际 effective_status 和业务权限以服务端为准。

  | 状态 | 时间文字 | 进度 | 普通参与者主要按钮 |
  |---|---|---|---|
  | 草稿，仅管理页面 | 未发布 | 不显示 | 编辑草稿，仅创建者可用 |
  | 未开始 | 开始于某时间 | 空条＋尚未开始 | 查看详情 |
  | 进行中，有上限 | 距结束多久 | 实际选票进度 | 查看投票 |
  | 进行中，无上限 | 距结束多久 | 时间进度 | 查看投票 |
  | 达上限结束 | 已满额 | 选票进度 100% | 查看结果 |
  | 到期结束，有上限 | 已结束 | 保留实际比例，例如 12/20、60% | 查看结果 |
  | 到期结束，无上限 | 已结束 | 时间进度 100% | 查看结果 |
  | 提前关闭 | 提前结束 | 票数保留实际值；时间冻结在关闭时刻 | 查看结果 |

  提前关闭的时间进度使用 closed_at 替代当前时间，仍限制在 0%–100%；未开始就关闭时可以为 0%。缺少可靠关闭时间时显示“提前结束”，不继续增长或伪造冻结比例。

  结束原因必须有可靠数据支撑，不能看到比例为 100% 就推断“因满额关闭”。closed_at 本身也不一定能区分手动关闭和满额关闭。无法区分时统一显示已结束。

  表中按钮需叠加访问权限；不能因结束就绕过登录或密码。管理列表的主要操作使用管理／查看详情，草稿可使用编辑草稿，避免把普通参与与管理动作混在一起。

## 身份、公开性和实时结果

* **五个设置各自负责一种行为，组合时叠加，不创建 32 套布局。**

  | 设置／访问者状态 | 展示和操作 |
  |---|---|
  | 公开 | 进入正常公开列表 |
  | 私密 | 不进入公开 Overview，只在允许的管理或授权入口展示 |
  | 记名，访客访问 | 进入投票前要求登录 |
  | 匿名 | 沿用浏览器凭据，无需注册；不展示身份头像 |
  | 私密，尚未解锁 | 先完成密码授权，不展示受保护的正文、选项或结果 |
  | 单选 | 显示单选，进度按选票份数计算 |
  | 多选 | 显示多选，进度仍按选票份数计算 |
  | 创建者／管理员 | 沿用管理权限，不用普通参与者的结果限制覆盖管理权限 |

  若列表响应不包含个性化权限，不臆测用户已解锁：主要按钮可统一为查看投票／查看详情，进入后由既有访问流程决定登录或输入密码。未经授权的私密投票不能通过增加卡片摘要或计数被公开发现。

* **实时结果控制选项结果，不控制容量计数。**

  allow_live_results=true：进行中且有结果访问权限时，提供查看结果次级入口。allow_live_results=false：普通参与者在进行中没有结果入口，可显示结束后公布。未开始时不向普通参与者开放结果。

  已结束允许查看结果，但仍须满足登录及私密访问要求。创建者和管理员沿用现有管理查看权限。

  本方案采用的明确口径：关闭实时结果只隐藏各选项票数、占比和领先者，不隐藏已收到的总选票数。因此有上限的卡片仍可显示 12/20。卡片首版不直接展示选项结果，即使实时结果已开启，也通过查看结果入口进入结果页。

  前端隐藏按钮不能代替后端鉴权；列表统计必须遵循所属投票的可见范围。

## 前后端数据与刷新

* **列表提供必要数据，前端负责展示与时间插值。以下为接口需求，不是已实现字段清单。**

  | 数据 | 来源与要求 |
  |---|---|
  | ballot_count | 后端统计选票父记录；不统计选择明细作为选票数 |
  | vote_limit | 上限，null 表示不限 |
  | starts_at、ends_at | 带时区的开始和结束时间 |
  | server_time | 服务端参考时间，校准时间进度；可统一放列表响应元数据 |
  | closed_at | 提前关闭时冻结时间进度 |
  | 结束原因 | 后端可靠提供；若现有结构无法支持，应扩展记录方式或统一显示已结束 |
  | effective_status | 服务端业务状态，决定状态标签和是否可参与 |
  | 结果访问权限 | 由后端规则决定，不能单凭 allow_live_results 判断 |
  | description | 如果摘要接口尚未提供，需补充可见范围内的描述或短摘要，不能逐卡拉详情 |

  标题、identity_mode、visibility、selection_mode 和 allow_live_results 沿用既有业务字段。所有响应保留项目统一外壳。实现前核对当前模型，不能仅凭本文认为新增字段已存在。

  后端应按当前列表页批量聚合选票数，不为每张卡片单独请求结果接口。计数、状态和结束原因应尽量来自同一一致性查询快照；展示时对比例限制范围不能代替服务端正确统计。

  前端时间进度可每分钟更新，使用同一个页面时钟，避免每卡各自建立定时器；依据 server_time 加本地经过时长估算当前时间。恢复标签页可见或跨越开始／截止边界时重新获取状态，不自行宣布投票已开放或关闭。

  票数进度随列表重新获取而更新，不用计时器猜测增长。若后续增加周期刷新，列表只发一个请求，避免重叠、隐藏页面暂停，失败保留最后一次有效数据并提供短反馈；不要承诺瞬时更新。

## 组合覆盖与验收

* **用维度组合测试同一组件。**

  记名／匿名 × 公开／私密 × 有／无票数上限 × 单选／多选 × 实时结果开／关，共 32 种设置组合。每种组合验证规则标签、进度选择和访问条件；再独立覆盖未开始、进行中、到期、满额和提前关闭。私密组合在管理／授权场景测试，不塞入公开列表。

  | 验收场景 | 预期 |
  |---|---|
  | 12 份选票，上限 20 | 蓝色 60%，显示 12/20 |
  | 多选 3 份选票，共 6 次选择，上限 20 | 蓝色 15%，显示 3/20，而不是 6/20 |
  | 无上限，10 小时窗口已经过 4 小时 | 紫色 40% |
  | 19/20 后到期结束 | 保留 95%，不补成 100% |
  | 满额关闭 | 显示已满额，实际计数与上限一致 |
  | 时间窗口经过 35% 时手动关闭 | 冻结 35%，之后不随时间增长 |
  | 实时结果关闭，进行中 | 可见容量计数，不可见选项结果入口 |
  | 私密、未授权 | 不因卡片或计数绕过权限 |
  | 数据缺失／时间异常 | 不显示 NaN、Infinity 或伪造 0% |
  | 长标题、两行描述、窄屏 | 不裁掉进度和按钮，标签正常换行 |

  进度条应有明确可访问名称、数值及文字说明；颜色不是唯一信息来源。关闭状态不能仅依靠灰色表达。实施后检查桌面与 390px 窄屏，验证键盘操作、焦点和文本对比度。

  本文件只规定展示和数据语义；实施时先核对后端统计与权限，再实现共享卡片和回归测试。保留原有正常投票数据，不增加产品内“示例投票”分类。
